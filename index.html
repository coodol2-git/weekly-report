사용방법

웹 페이지 사용

PC Chrome 또는 Edge에서 게시 주소를 직접 열고 폴더를 연결합니다. CSV는 선택한 Drive/NAS 폴더에 저장하며 사이트로 업로드하지 않습니다. 기존 로컬 HTML의 임시저장본은 웹 페이지로 자동 이전되지 않으므로 CSV로 저장해 가져오세요.

관리자 최초 설정

  1. Google Drive의 내 드라이브 안에 분석지원팀 주간보고 폴더를 만듭니다. 이 상위 폴더는 관리자만 접근하도록 설정합니다.
  2. 게시된 HTTPS 페이지 또는 이 HTML을 PC의 Chrome 또는 Edge에서 열고 ‘관리자 — 상위 폴더’를 선택합니다. ‘Drive / NAS 폴더 연결’에서 보고서 상위 폴더를 선택합니다.
  3. 개인 폴더 준비를 누르면 6명의 개인 폴더와 종합보고 폴더를 만듭니다. 기존 파일은 삭제하지 않습니다.
  4. Google Drive 웹에서 각 개인 폴더만 해당 직원의 Google 이메일에 편집자로 공유합니다. 일반 액세스는 ‘제한됨’으로 설정합니다. 상위 폴더·종합보고·기존 _관리 폴더는 직원에게 공유하지 않습니다. 이전에 직원에게 부여한 상위 폴더 권한과 별도 파일 공유 권한도 확인하세요.
  5. 다른 관리자는 상위 폴더에 권한을 부여합니다. Drive 공유 설정은 이 HTML이 자동으로 변경하지 않습니다.

직원 사용

  1. 직원은 PC Google Drive 앱에 본인 Google 계정으로 로그인합니다. 공유받은 본인 폴더를 PC에서 사용할 수 있게 준비합니다.
  2. 게시된 HTTPS 페이지 또는 이 HTML을 열고 ‘직원 — 본인 폴더’, 본인 이름을 선택합니다.
  3. ‘Drive / NAS 폴더 연결’에서 본인 이름의 폴더만 선택합니다. 선택한 이름과 폴더명이 다르면 연결하지 않습니다.
  4. 보고 월·주차를 선택하고 내용을 작성합니다. 상세 기록과 계획은 추가 버튼으로 늘릴 수 있습니다.
  5. 임시저장은 현재 브라우저에만 보관합니다. 저장은 개인 폴더의 연도/주차/담당자.csv에 반영합니다. Drive 앱에서 동기화 완료를 확인하세요.
  6. 불러오기는 기존 CSV·HTML·JSON을 읽습니다. 개인은 본인 보고서만 불러올 수 있으며, 저장을 눌러 폴더에 반영합니다.

관리자 조회·취합

관리자는 상위 폴더를 연결하고 작성자·주차를 선택해 개인별 CSV를 조회합니다. 개인 보고서 화면은 읽기 전용입니다. ‘팀 종합보고’에서 6명의 저장본을 모아 조회하고 ‘종합보고 저장’으로 종합보고/연도/주차.csv에 보관합니다. 임시저장본은 취합하지 않습니다.

v8의 연도/주차/담당자.csv가 상위 폴더에 있다면 v8 CSV 가져오기를 누릅니다. 개인별 폴더로 복사하며 기존 원본은 유지합니다. 같은 주차의 파일이 있으면 덮어쓰기 전에 확인합니다. 이전 HTML·CSV도 관리자 ‘불러오기’로 가져올 수 있습니다.

권한과 연결 방식

v9는 자체 ID/PW, 계정 신청·승인, 비밀번호 변경을 사용하지 않습니다. Google 계정 관리는 Google에서 하고 실제 파일 접근은 Drive 공유 권한이 결정합니다. ‘관리자’ 선택은 화면 모드이며 Google 관리자를 인증하는 기능이 아닙니다. 직원이 상위 폴더나 다른 개인 폴더를 볼 수 없도록 Drive 권한을 먼저 설정해야 합니다.

이 HTML은 Drive API 로그인이나 공유 설정을 직접 수행하지 않습니다. PC에서 사용자가 선택한 폴더에만 접근합니다. 폴더 연결은 HTML을 다시 열 때 선택합니다. 개인 Google 계정의 ID·비밀번호를 다른 사람에게 전달하지 마세요.

같은 보고서를 여러 PC에서 동시에 수정하지 말고 순차 저장하세요. 이전 파일은 개인별 ‘이력’ 폴더에 남습니다. Drive 동기화 지연에 따른 충돌을 완전히 방지하는 서버 방식은 아닙니다.

브라우저 데이터를 삭제하면 임시저장본이 사라질 수 있습니다. 폴더의 CSV는 유지됩니다. NAS 전환 시 같은 폴더 구조를 복사하고, NAS에서도 개인별 접근 권한을 설정한 뒤 저장 폴더를 다시 선택합니다.

‘새로고침’은 현재 보고서 입력 내용을 비웁니다. 폴더 저장본을 즉시 삭제하지는 않습니다. 오른쪽 아래 화살표는 화면 맨 위로 이동합니다.
