사용방법

개인 보고서 작성

  1. 관리자가 전달한 본인 전용 링크로 접속합니다. Google Drive 앱 설치나 API 주소 입력은 필요 없습니다.
  2. 화면 하단의 본인 이름 작성 예시 버튼을 누르면 담당 업무에 맞는 가상 예시로 채웁니다. 현재 입력이 교체되므로 필요한 내용은 먼저 보내기로 저장하세요. 예시는 자동 제출되지 않습니다. 관리자는 작성자를 선택한 뒤 해당 인원 작성 예시 버튼으로 조회용 팝업을 열 수 있습니다.
  3. 주차를 선택하고 업무개요, 상세 기록, 차주계획을 작성합니다. 추가 기록은 하단 버튼으로 늘립니다.
  4. 임시저장은 현재 브라우저에만 보관합니다. 보내기를 누르면 관리자 Google Drive의 본인 폴더에 CSV로 저장됩니다.
  5. 저장본 새로고침은 해당 주차의 Drive 저장본을 다시 읽습니다. 불러오기는 기존 CSV·HTML·JSON 파일을 가져옵니다.
  6. 다른 저장본과 충돌하면 덮어쓰기 확인을 거칩니다. 이전 CSV는 이력 폴더에 보관합니다.

관리자

관리자 전용 링크에서는 전체 직원 보고서를 조회하고 기존 자료를 가져오며 종합보고를 Drive에 저장할 수 있습니다. 작성자 순서는 김신애 / 김윤미 / 이유빈 / 홍세민 / 장미 / 김민주입니다.

PC에서 간편하게 접속하기

  1. 본인 전용 링크로 한 번 접속한 뒤 상단의 PC 바로가기 만들기를 누릅니다.
  2. 다운로드 폴더의 분석지원_주간보고_본인이름_바로가기.zip을 우클릭 → 모두 압축 풀기를 선택합니다. 안에 있는 .url 바로가기를 Windows 바탕화면으로 옮긴 뒤 더블클릭하세요. 브라우저에서 확장자가 .download로 바뀌는 문제를 피하도록 ZIP으로 제공합니다.
  3. 브라우저 북마크로도 사용할 수 있습니다. 본인 링크로 접속한 상태에서 Ctrl+D를 누르고 저장하세요. 다음부터 북마크를 클릭하면 됩니다.

바로가기에는 개인 접속정보가 포함됩니다. 본인 PC에서만 사용하고 다른 사람에게 전달하지 마세요. 관리자가 접속 링크를 재발급하면 새 링크로 바로가기도 다시 만드세요.

개인 링크와 접속 종료

개인 링크를 가진 사람은 해당 직원 자료에 접근할 수 있습니다. 링크를 다른 사람에게 전달하지 마세요. 계정 비밀번호 인증 방식은 아닙니다. 공용 PC에서는 접속 종료를 누르고 탭을 닫으세요. 접속 종료 시 본인의 브라우저 임시저장본도 삭제합니다. 관리자가 링크를 다시 발급하면 이전 링크는 모두 해제됩니다.

전송 오류가 나면 임시저장 후 연결을 확인하세요. 성공 메시지는 Drive 저장 응답을 받은 뒤에만 표시합니다.
